# Import CSV contract

Generated by `npm run import:contract` — do not edit by hand. Re-run it after changing any import spec.

## Rules that apply to every file

- UTF-8, comma separated, one header row.
- Header matching ignores case, spaces, underscores and hyphens, and accepts the aliases listed per column — an existing export often needs no renaming.
- Unrecognised columns are reported back to the admin and ignored, never rejected.
- Empty optional cells are fine; empty required cells fail the row.
- Money and other amounts are whole numbers. `1500.50` fails rather than being rounded.
- Quote any cell containing a comma, quote or line break, doubling inner quotes (`"a ""b"", c"`). Line breaks inside quoted cells are handled.
- Max 4 MB per file, max 100,000 rows.

## Import order

Each entity's references must already exist, so export and import in this order:

1. **branches** (no dependencies)
2. **employees** (needs branches)
3. **customers** (no dependencies)
4. **dresses** (needs branches)

## branches

Existing records are matched on **shortCode** — a row whose key already exists updates that record instead of creating a duplicate. A key repeated inside one file fails both rows.

| Column | Required | Accepts | Also accepted as | Example |
| --- | --- | --- | --- | --- |
| `shortCode` | **yes** | text, max 8 chars | `short_code`, `code`, `branchcode`, `branch_code` | MAADI |
| `nameEn` | **yes** | text, max 128 chars | `name_en`, `name`, `englishname` | Maadi Branch |
| `nameAr` | **yes** | text, max 128 chars | `name_ar`, `arabicname` | فرع المعادي |
| `addressEn` | no | text | `address_en`, `address` | 12 Road 9, Maadi |
| `addressAr` | no | text | `address_ar` | ١٢ شارع ٩، المعادي |
| `phone` | no | text, max 32 chars | `telephone`, `mobile` | +20 2 2358 1234 |

Header row:

```csv
shortCode,nameEn,nameAr,addressEn,addressAr,phone
```
